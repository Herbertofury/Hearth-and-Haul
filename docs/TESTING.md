# Testing

## Evidence categories

Hearth and Haul separates testing records into two categories.

## Historical certification

Recovered historical certification covers the Backpacks 2.0.2.4 artifact and its original validation scope.

Recorded environment:

- Minecraft 1.20.1
- Forge 47.4.23
- Java 17

Reported historical checks include build, packaged server, client validation, persistence, rendering, crafting, and compatibility checks.

## Future reproduced tests

New Hearth and Haul validation runs must be recorded separately with:

- date
- environment
- exact artifact tested
- result
- logs or evidence reference

Historical evidence must never be presented as a newly executed test.
