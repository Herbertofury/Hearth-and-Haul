# Hearth and Haul

**Hearth and Haul** is a Minecraft backpack adventure project built from the recovered Backpacks 2.0.2.4 foundation.

The goal is to turn portable storage into a living adventure system: creature-inspired backpacks, deeper storage compatibility, and eventually portable homes that feel like carrying your own hearth with you.

## Important status note

This repository distinguishes:

- **Verified historical evidence** — preserved build/test records from the original recovery process.
- **Repository contents** — newly organized documentation and source publication work.
- **Future roadmap** — ideas that are not yet implemented.

No unverified release claims or fabricated screenshots are published.

## Existing content

Existing creature-themed work, including Warden, Bee, and Creaking variants, is preserved as existing project content. Future work expands this system with additional variants, not a claim that these existing variants do not exist.

## Vision

Future Hearth and Haul features may include:

- Sophisticated Backpacks and Sophisticated Storage ecosystem improvements
- more creature-themed backpack variants
- living companion-style storage
- dimensional backpacks / portable homes
- stronger adventure progression
